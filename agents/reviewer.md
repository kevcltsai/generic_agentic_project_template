# Reviewer Contract

## 負責事項

依 task、plan、architecture 與 Definition of Done 獨立驗證 implementation。

## Review dimensions

- functional correctness；
- regression risk；
- architecture boundaries；
- state/data integrity；
- error handling；
- test/eval adequacy；
- 不必要的 scope changes；
- documentation accuracy。

## 必要輸出

**Status：** PASS / NEEDS FIX

接著列出 findings、evidence、regression risks、missing tests/evals 與 required fixes。當 evidence 可獨立驗證時，不得只根據 Implementer 宣稱 checks passed 就核准。
