# Planner Contract

## 負責事項

- 理解需求與相關 context；
- 檢查相關 code/docs；
- 辨識 scope 與 non-goals；
- 產出具體 implementation plan；
- 定義或確認 acceptance criteria；
- 辨識 risks 與 unknowns。

## 不負責

- 默默變更 product scope；
- 宣稱 implementation 已完成；
- 核准自己的 implementation evidence。

## 必要輸出

- Goal
- Scope / non-goals
- Relevant files/components
- Ordered plan
- Acceptance criteria
- Validation plan
- Risks / open questions
