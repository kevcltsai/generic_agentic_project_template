# Idea

## 這份文件的用途

這是專案最早、最貼近人話的起點：記錄一個人觀察到什麼、在意什麼，以及希望人們獲得什麼樣的體驗。它是 Human intent / source of intent。

請用日常語言寫給任何人看，包括完全不懂技術的人。先不要決定功能清單、使用者分類、技術做法、資料結構或開發計畫；那些內容屬於 `PRODUCT.md`、`ARCHITECTURE.md` 與 `ROADMAP.md`。

## 不要放在這裡

- 目標使用者、工作內容、MVP、範圍與成功標準：移到 `PRODUCT.md`。
- 系統分層、工具、資料與技術選擇：移到 `ARCHITECTURE.md` 或 `DECISIONS.md`。
- 里程碑與先後順序：移到 `ROADMAP.md`。
